# Acceptance Criteria - F127

## Functional
1) 選 202611～202612 查詢：每個品項一列，顯示 2026-11、2026-12 各月合計與全期合計；
   單月數字與該月單月彙總頁的「更改後小計」（各通路加總）一致。
2) 範圍含未關帳月份時，該月資料取各通路最新上傳（含禮品），表頭標示「未關帳」。
3) 已關帳月份取最新表單版本：生管於單月彙總儲存第 2 版後，跨月彙整該月數字反映第 2 版。
4) 只在其中一個月有預估的品號仍會列出，其他月份顯示 0。
5) 跨年範圍（例：202611～202702）可正常查詢，月份依時間排序。
6) 範圍超過 4 個月或起 > 迄：前端擋下並提示；直接呼叫 API 回 400。
7) 有備註的品項顯示「備註」按鈕，彈窗內依「月份 → 通路」順序逐行列出 `[通路/M月] 內容`；無備註顯示「-」。
8) 頁面唯讀，無編輯／儲存按鈕。
9) 匯出 CSV 內容與畫面一致，備註多則以換行分隔於同一儲存格。
10) 無 `sales_forecast.update_after_closed` 權限的使用者呼叫 API 回 403。

## Build / Test
11) `FormSummaryService` 單元測試涵蓋：已關帳＋未關帳混合、依品號跨月合併、僅單月出現的品號補 0、備註排序。
12) 控制器測試或單元測試涵蓋第 6 項的 400 情境。
13) 前端 `CrossMonthSummary` 測試涵蓋：查詢結果渲染、未關帳標記、備註彈窗、範圍超過 4 個月的提示。
14) F126 既有測試維持通過；後端與前端整體失敗清單不多於基準（目前後端 57、前端 14 個既有失敗）。

## Manual Test Steps
1) 以 pm / pm123 登入，進銷售預估頁，切到「跨月彙整」頁籤。
2) 選 2026-11～2026-12 查詢，對照兩個月的單月彙總確認數字（第 1 項）。
3) 確認未關帳月份標記、備註彈窗順序、匯出 CSV。
4) 選 2026-11～2027-03（5 個月）確認被擋下。
